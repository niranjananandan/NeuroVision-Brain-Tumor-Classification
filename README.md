## 📌 Overview
NeuroVision is an automated diagnostic tool that utilizes a custom, lightweight Convolutional Neural Network (CNN) to classify human brain Magnetic Resonance Imaging (MRI) scans[cite: 1, 2]. The model efficiently distinguishes between healthy brains ('Normal') and those with distinct structural deformations ('Tumor')[cite: 1, 6]. Achieving an ~82% validation accuracy, this project aims to provide a rapid second-opinion tool for medical professionals while balancing computational efficiency with high recall[cite: 1, 2].  

## 📊 Dataset Specifications
The model was trained on a dataset of 253 MRI scans sourced from open-source repositories[cite: 1, 6].  
* **Class 0 (Normal / 'no'):** Healthy brain MRI scans without visible tumor masses[cite: 1, 6].  
* **Class 1 (Tumor / 'yes'):** Brain MRI scans showing abnormal white patches or structural deformations[cite: 1, 6].  
* **Data Split:** The dataset was split using an 80:20 ratio, resulting in 202 images for training and 51 images for testing[cite: 1, 6].  

## ⚙️ Data Preprocessing Pipeline
To ensure consistent and mathematically optimized inputs for the neural network, the raw images underwent the following pipeline[cite: 1]:  
* **Grayscale Conversion:** Images were converted to a single color channel to reduce computational complexity while retaining necessary structural features[cite: 1, 6].  
* **Resizing:** All scans were uniformly resized to a fixed resolution of 128x128 pixels[cite: 1, 6].  
* **Normalization:** Pixel intensity values were scaled from 0-255 down to a 0.0-1.0 range (Min-Max Normalization) by dividing by 255.0 to prevent exploding gradients and aid the optimizer[cite: 1, 6].  

## 🧠 Model Architecture
The project uses a Sequential CNN built via the TensorFlow/Keras API[cite: 1, 5].  
* **Feature Extraction:** Three sequential convolutional blocks (Conv2D) utilizing 32, 64, and 128 filters to automatically extract hierarchical features from the pixels[cite: 1, 5].  
* **Spatial Downsampling:** MaxPooling2D layers following the convolutional blocks to reduce spatial dimensions and compress the data[cite: 1, 5].  
* **Transition:** A Flatten layer converts the 2D feature maps generated by the convolutional blocks into a 1D numerical array[cite: 1, 5].  
* **Fully Connected Layers:** A Dense layer with 128 neurons acts as the model's interpreter[cite: 1, 5].  
* **Regularization:** A Dropout layer (0.5 rate) randomly deactivates 50% of neurons during training to enforce robust learning and prevent overfitting[cite: 1, 5].  
* **Output Layer:** A final Dense layer with a single neuron using the 'sigmoid' activation function outputs a probability score for the binary classification[cite: 1, 5].  

## 📈 Training & Evaluation
* **Configuration:** The model was compiled using the highly efficient Adam optimizer and 'binary_crossentropy' loss[cite: 1, 7].  
* **Training Parameters:** Trained over 20 epochs with a batch size of 16[cite: 1, 7].  
* **Results:** The model achieved approximately 82% validation accuracy[cite: 1, 2]. Overall performance was carefully monitored using a Classification Report (Accuracy, Precision, Recall, F1-Score) and a Confusion Matrix heatmap to assess False Negatives and True Positives[cite: 1, 9].  

## 🚀 Future Scope
The natural progression of this research is to deploy the trained model as a functional web application[cite: 1, 2]. This would provide an accessible interface for end-users and medical practitioners to upload raw MRI scans and receive automated, real-time classification predictions[cite: 1, 2].
